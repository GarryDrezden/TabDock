# TabDock

TabDock — Chrome-расширение, диспетчер браузерного пространства: разделы первого уровня, сохранённые ссылки и рабочие наборы.

<img width="1536" height="1024" alt="TabDock valknut" src="https://github.com/user-attachments/assets/0ac3bb7b-01f7-4d3e-a500-1e69c7a0f882" />

Структура хранится отдельно от открытых вкладок. Можно закрыть Chrome и на следующий день снова поднять нужный набор одной кнопкой.

Источник продуктовой модели: [`PRODUCT.md`](./PRODUCT.md).

## Что есть в v0.1

Первый рабочий вертикальный срез Core Loop:

- постоянная боковая панель (Side Panel);
- выбор стороны панели (слева / справа) в header;
- создание раздела;
- сворачивание / разворачивание раздела;
- добавление текущей вкладки в раздел;
- индикатор open / closed у каждой ссылки;
- клик по открытой ссылке переключает на существующую вкладку, без дубля;
- клик по закрытой ссылке открывает её;
- своё название у сохранённой ссылки;
- меню действий у ссылки;
- изменение порядка ссылок и перенос между разделами;
- открыть отдельную копию;
- закрыть открытую вкладку, не удаляя ссылку;
- удалить ссылку из TabDock, не закрывая вкладку;
- «Открыть всё» для раздела;
- системный раздел «Временное»;
- «Отложить текущую вкладку» в шапке;
- «Сохранить и закрыть» через Shift+клик по «+» раздела;
- сохранение структуры в `chrome.storage.local` (переживает перезапуск Chrome).

## Технологии

- Chrome Extension Manifest V3
- React 18
- TypeScript strict
- Vite
- обычный CSS
- `chrome.sidePanel`, `chrome.tabs`, `chrome.windows`, `chrome.storage.local`

## Установка зависимостей

```bash
npm install
```

## Development / build

```bash
npm run build
```

`npm run dev` запускает обычный Vite-сервер. Для реальной работы с вкладками Chrome нужен production-build и установка как unpacked-расширение.

Готовая папка расширения:

```
dist/
```

Внутри должны быть `manifest.json`, `index.html`, `background.js`, `icons/` и `assets/`.

## Как установить локально

1. Соберите проект: `npm run build`
2. Откройте `chrome://extensions`
3. Включите **Developer mode**
4. Нажмите **Load unpacked**
5. Выберите папку `dist` в корне репозитория

## Как открыть TabDock

Нажмите иконку TabDock (валькнут) на панели инструментов Chrome. Откроется боковая панель.

Если иконки не видно: пазл расширений → закрепите TabDock.

Сторону панели (слева или справа) Chrome задаёт сам. В header TabDock есть переключатель: он показывает текущую сторону и подсказывает, как сменить её в Chrome (шапка панели или Настройки → Внешний вид → Боковая панель).

## Manual test checklist

Первый запуск:

1. `npm install`
2. `npm run build`
3. `chrome://extensions` → Developer mode → Load unpacked → `dist`
4. Клик по иконке TabDock → Side Panel открывается
5. `+` → ввести `Работа` → Enter → раздел появляется
6. Открыть GitHub → в разделе нажать `+` → ссылка появляется со статусом open
7. Закрыть вкладку GitHub в Chrome → ссылка остаётся, статус становится closed, счётчик меняется
8. Клик по закрытой ссылке → вкладка открывается
9. Клик ещё раз → дубль не создаётся, Chrome переключается на существующую вкладку
10. Добавить ещё страницы, закрыть часть, нажать ▶ «Открыть всё» → открываются только отсутствующие
11. Полностью закрыть Chrome, открыть снова → разделы и свёрнутость на месте, open/closed соответствует браузеру

Ширина панели: проверить примерно на 320 / 360 / 400 / 500 px. Горизонтального скролла быть не должно.

## Что сознательно не реализовано

Остаётся в продукте по `PRODUCT.md`, но не входит в v0.1:

- поиск;
- «Открытые без раздела»;
- drag & drop разделов;
- переименование / удаление разделов;
- изменение URL;
- закрыть все вкладки раздела;
- Chrome Tab Groups;
- import / export JSON;
- privacy / presentation mode;
- sessions, notes, aliases, sync, аккаунты, AI.

Следующую крупную итерацию начинаем после реального использования v0.1.
