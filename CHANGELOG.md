# Changelog

## 2026-08-17

### Резервная копия

В глобальном меню ⋮ можно экспортировать структуру TabDock в JSON и восстановить её из файла. Перед заменой данных показывается preview. Импортируется только постоянная структура: разделы, ссылки, названия, иконки, порядок. Open/closed заново вычисляется по вкладкам Chrome.

### Управление разделами

У пользовательского раздела появилось меню ⋮: переименовать, сменить иконку, закрыть вкладки раздела и удалить раздел. Системное «Временное» без этого меню и не участвует в перестановке разделов.

Разделы можно менять местами за ручку слева. Порядок сохраняется.

«Закрыть вкладки раздела» закрывает открытые Chrome-вкладки сохранённых ссылок, включая отдельные копии с тем же URL. Сам раздел и ссылки остаются.

Удаление раздела убирает его и сохранённые ссылки из TabDock, но не закрывает вкладки браузера.

### Временное

Внизу дерева появился системный раздел «Временное». Кнопка в шапке откладывает текущую вкладку: сначала сохраняет ссылку, затем закрывает вкладку. Если страница уже есть во «Временном» или в постоянном разделе, второй экземпляр не создаётся, вкладка всё равно закрывается.

Ссылки из «Временного» можно открыть, переименовать, удалить, перенести через меню или перетащить в постоянный раздел. «Открыть всё» для этого раздела нет.

### Сохранить и закрыть

Shift+клик по «+» у обычного раздела сохраняет текущую вкладку туда и закрывает её. Обычный клик по-прежнему только добавляет ссылку.

## 2026-08-16

### Меню действий ссылки

Карандаш у строки заменён на компактное меню ⋮. Из него можно переименовать ссылку, переместить в другой раздел, открыть отдельную копию, закрыть открытую вкладку и удалить ссылку из TabDock. Обычный клик по строке по-прежнему переключает на существующую вкладку или открывает закрытую.

### Перенос между разделами

Ссылку можно перенести в другой раздел через меню или перетаскиванием. Drop на шапку раздела добавляет ссылку в конец, в том числе если раздел свёрнут. В развёрнутом разделе можно вставить ссылку между существующими. Если такой же URL уже есть в целевом разделе, перенос отменяется.

### Вторая строка ссылки

Во второй строке показывается только hostname. Полный URL остаётся в подсказке при наведении.

### Порядок ссылок в разделе

Ссылки внутри раздела можно менять местами: перетаскивание за ручку слева. Порядок сохраняется в `chrome.storage.local` и используется «Открыть всё».

### Своё название у ссылки

Своё название у сохранённой вкладки: пункт «Переименовать» в меню ссылки открывает inline-поле. Enter или клик вне поля сохраняет, Escape отменяет. Пустое имя возвращает исходный title страницы. Оригинальный title не затирается.

### Сторона Side Panel

В header добавлен переключатель «слева / справа».

Chrome не даёт расширению программно двигать боковую панель: сторона задаётся в самом браузере. TabDock:

- показывает текущую сторону, если Chrome 140+ (`sidePanel.getLayout`);
- запоминает выбранную сторону в `chrome.storage.local`;
- если выбранная сторона не совпадает с Chrome, подсказывает, как сменить её в шапке панели или в Настройки → Внешний вид → Боковая панель.
